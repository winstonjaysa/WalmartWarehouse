# Gateflow parts v4 — Walmart Canada backroom models (Three.js r160)

Contract: `export function build(THREE, mats, opts={}) -> THREE.Group`. Metres, y up, origin = floor centre of footprint.
`group.userData = { name, dims:{w,h,d}, pivots:{...}, drawCalls }`. No three imports; every module falls back if a `mats` key is missing.
Materials: cardboard/wood roughness 0.82–0.85, metalness 0; plastics/vc ≈0.6; cartons and boards vary ±6 % value with a slight hue shift.

## Integration notes
- **Seat:** truck `userData.seatPoint` (`object` = child Object3D `'seat'`, also `getObjectByName('seat')`; tractor-trailer has it on the tractor and the combined group). `seatedDrivePose(worker, seat)` parents the worker to the seat with its hips on the seat origin, facing seat +z. Box truck seat world (0.5, 1.82, 2.08); tractor (0.55, 2.2, 8.4).
- **Jack pull:** build the jack, `updateMatrixWorld`, take `jack.userData.gripPoint.object.getWorldPosition()`. Set the handle angle `-acos((handY − 0.47 − lift)/0.708)` (≈ −0.76 for a 1.1 m hand, raised). Place the worker facing away from the forks about (−0.13, −0.35) from the grip in x/z, then `jackPullPose(worker, gripWorld)`. The IK clamps at full reach, so nudge the worker by the residual hand→grip x/z and re-pose (see `compose()` in preview/contact.html).
- **Animation helpers:** `setRearDoor(g, f)` (box truck), `setCurtain(g, 'L'|'R', f)` and `setLandingGear(g, f)` (tractor-trailer), `walkPose(g, t)`, `carryPose`, `restPose`, `attachHandsTo`, `handWorld`.
- **Pallets:** `opts.palletColor` on wrappedSkid/popSkid overrides the seed paint.
