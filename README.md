# WalmartWarehouse

Live 3D operations dashboard of a Walmart-style regional distribution centre (Three.js, single HTML file).

- `walmart-dc.html` is the current build. Open it in a browser.
- `builds/` holds frozen snapshots (`walmart-dc_vN.html`), logged in `builds/CANDIDATES.txt`.
- `src/` holds the builder sources. `parts/` holds the modules: models, signs, sorter, tour, camera, rack cartons and post-FX.
- `assets/` holds the Blender GLB models. `qa/review.md` is the QA gate.

Concept demo · not affiliated with Walmart Inc. · All data synthetic.
